# AirBnb Sanity Frontend

This is the frontend for an AirBnB clone that showcases properties fetched from a Sanity.io content management system. The application allows users to browse properties on a dashboard with an interactive map and view detailed property pages with reviews, images, and location information.

## Core Features

- **Property Dashboard**: Display all properties in a feed with images and pricing, alongside an interactive map showing all property locations
- **Property Detail Pages**: View complete property information including multiple images, reviews, host details, amenities, and embedded maps
- **Google Maps Integration**: Interactive maps powered by the Google Maps API with location markers for properties
- **Image Management**: Optimized image serving from Sanity with dynamic URL builders for various dimensions and formats
