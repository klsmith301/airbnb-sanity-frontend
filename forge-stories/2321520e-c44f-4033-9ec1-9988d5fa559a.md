## Goal
Add a `CONTRIBUTING.md` file at the repository root with a single paragraph explaining how to run the **Airbnb Sanity.io Frontend** project locally.

---

## Tasks

### 1. Create `CONTRIBUTING.md`
**File:** `CONTRIBUTING.md` (new, repository root)

Write a short Markdown document containing:
- A top-level heading `# Contributing`.
- One paragraph covering the local-development workflow, drawn from what the README and `package.json` already document:
  1. Clone the repository.
  2. Copy/create a `.env.local` file with the three required environment variables (`NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET`, and a Google Maps API key).
  3. Install dependencies: `npm i`.
  4. Start the dev server: `npm run dev`.
  5. Open `http://localhost:3000` in a browser.

Keep it to one cohesive paragraph (no sub-headings or bullet lists inside the paragraph) as the requirement asks for.

---

## Acceptance criteria
- `CONTRIBUTING.md` exists at the repository root.
- The file contains exactly one paragraph (after the heading) describing the local-run steps.
- All commands mentioned match those in `package.json` (`npm i`, `npm run dev`).
- The environment-variable names match those used in `sanity.js` (`NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET`).
- No existing files are modified.
